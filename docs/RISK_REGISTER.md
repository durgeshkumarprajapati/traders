# Risk Register (Phase 0)

| ID  | Risk                                                                     | Likelihood | Impact   | Mitigation                                                                                                                                                                                                                                                                                                                                       |
| --- | ------------------------------------------------------------------------ | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| R1  | Unverified demo claims/contacts/GST published                            | High       | High     | Content gate: all business facts from BusinessSettings; remove banners; pre-release grep for demo strings                                                                                                                                                                                                                                        |
| R2  | Admin demo credentials/UI leaked into prod                               | Low        | Critical | **Mitigated (Phase 7):** Demo credentials excluded from UI and codebase; admin provisioned manually via Supabase Auth + `admin_profiles`; no public signup/register routes; static security test `security.test.ts` asserts absence of registration.                                                                                             |
| R3  | Stale/false price shown as live                                          | Med        | High     | **Mitigated (Phase 11):** Centralized catalogue resolution in `src/features/catalogue/server.ts` guarantees Priority 1 live data and Priority 2 static fallback. When fallback is active, all prices are strictly `null` (rendered as 'Rate on request', zero fabricated prices) and `CatalogueFallbackNotice` informs customers.                |
| R4  | Component sheets missing → fidelity drift                                | High       | Med      | Request export; derive from page markup; visual review gate                                                                                                                                                                                                                                                                                      |
| R5  | Off-palette colours/dark surfaces spread                                 | High       | Med      | Token-only Tailwind, lint rule for arbitrary colours, status map                                                                                                                                                                                                                                                                                 |
| R6  | Foundation tokens wrong (radius naming)                                  | Certain    | Med      | Rebuild tokens in Phase 1 first task                                                                                                                                                                                                                                                                                                             |
| R7  | Google Sheets quota/latency, concurrent edits, manual edits corrupt data | Med        | High     | **Mitigated (Phase 8 & 11):** In-memory 30m cache with atomic `invalidateSheetsCache()` invalidation; optimistic concurrency checks (`expectedUpdatedAt`); row-level cell updates. If Sheets fails or times out, `loadCatalogue()` gracefully switches to static fallback catalogue without site interruption.                                   |
| R8  | Sheets lacks fields UI needs (SKU, stock qty)                            | High       | Low      | Drop from UI or add columns by decision                                                                                                                                                                                                                                                                                                          |
| R9  | Duplicate / spam enquiries                                               | Med        | Med      | Idempotency key, rate limit, honeypot                                                                                                                                                                                                                                                                                                            |
| R10 | Email failure loses lead                                                 | Med        | High     | **Mitigated (Phase 9 & 11):** Two-stage enquiry persistence saves enquiry and outbox row in Supabase before notification attempt; admin retry available. In Phase 11, degraded email-only fallback in `submit.ts` delivers enquiries directly via Web3Forms with in-memory sliding rate limiting if Supabase is down, preserving customer leads. |
| R11 | Admin routes protected only by proxy                                     | Low        | Critical | **Mitigated (Phase 7):** Multi-tiered defense implemented: (1) `proxy.ts` optimistic redirects; (2) `(console)/layout.tsx` server-side `requireAdminSession()`; (3) Server Actions protected via `withAdminAction()`; (4) Route Handlers protected via `requireAdmin()`; (5) PostgreSQL RLS enforced via `public.is_admin()`.                    |
| R12 | `cacheComponents` pitfalls (dynamic access without Suspense)             | Med        | Med      | Follow docs in `node_modules/next/dist/docs`; build checks                                                                                                                                                                                                                                                                                       |
| R13 | Admin not responsive in design                                           | High       | Med      | **Mitigated (Phase 8):** Responsive admin console layouts implemented: mobile drawer/navigation sidebar, horizontally scrollable data tables with wrapping controls, stacked grid form fields (`grid-cols-1 md:grid-cols-2`), and mobile touch-friendly buttons.                                                                                 |
| R14 | PII (IP, phone) storage/privacy                                          | Med        | Med      | Don't store IP; privacy notice; RLS                                                                                                                                                                                                                                                                                                              |
| R15 | Vercel Hobby commercial-use restriction                                  | Med        | Med      | Use Pro for production                                                                                                                                                                                                                                                                                                                           |
| R16 | Stitch images are temporary hosted URLs                                  | Certain    | Med      | Replace with Cloudinary assets; supply real photos                                                                                                                                                                                                                                                                                               |
| R17 | Build env: Tailwind auto-scan of project root                            | Low        | Low      | Scoped `@source` to `src/` (done)                                                                                                                                                                                                                                                                                                                |
| R18 | Fresh Google Sheet lacks required tabs or headers                        | High       | High     | **Mitigated (Phase 9 & 11):** Schema demonstration dataset created in `docs/sheets-template/demo-data/`. Phase 11 verified all 4 worksheets (`Categories`, `Brands`, `Products`, `BusinessSettings`) live in Google Sheets. Missing sheets trigger static fallback catalogue automatically.                                                      |
| R19 | Serverless execution timeout during notification retry processing        | Med        | Med      | **Mitigated (Phase 10):** Implemented 20-second execution deadline guard (`maxDurationMs = 20000`) in `processDueNotifications()` to break early and yield remaining notifications to the next scheduled cron tick; scheduled every 10 minutes in `vercel.json`.                                                                                 |
| R20 | Operational degradation silently unobserved in production                | Med        | High     | **Mitigated (Phase 10):** Operational health check endpoint `GET /api/health` queries core subsystems (app, sheets, database, notifications) without leaking secret values, returning structured JSON with no-cache headers and logging metrics.                                                                                                 |
| R21 | Live Supabase migrations not applied before deploying application        | High       | Critical | **Resolved (Phase 11):** Remote introspection confirmed `20261118000000_enquiries.sql` and `20261120000000_admin_auth.sql` applied on live Supabase instance with RLS active, `is_admin()` RPC function operational, and 1 admin profile row provisioned.                                                                                        |
