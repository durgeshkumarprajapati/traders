## Decisions on Phase 7: Admin Authentication & Authorization (2026-11-20)

## Decisions on the customer experience features (2026-11-23)

| #   | Decision                                                                                                                                                                                                                                                                                                          |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 41  | **Public enquiry reference is random** (`ENQ-XXXX-XXXX-XXXX`, 48 random bits from PostgreSQL's CSPRNG, unique). The reference is an identifier, never a credential; the tracking token is. Legacy sequential references remain valid.                                                                             |
| 42  | **Tracking credentials travel in the URL fragment**, not the query string, so they never reach server/CDN logs or Referer headers. Old query links are accepted once and rewritten.                                                                                                                               |
| 43  | **Tokens (tracking and quotation) are 256-bit random, hash-only at rest, expire after 90 days, and can be revoked or rotated.** Seeded tracking tokens use a domain-separated HMAC so retries are idempotent.                                                                                                     |
| 44  | **No OTP and no customer email delivery** until a provider exists: OTP needs an SMS provider (none configured); customer email is impossible with Web3Forms (server-side use needs a paid plan + IP whitelisting; no per-request recipient). Not built, not faked.                                                |
| 45  | **Quotation money is exact** (integer paise / BigInt in TypeScript; `numeric` in SQL, computed by the database). **No tax rate is assumed** — tax is an administrator-entered amount; GSTIN prints only if configured.                                                                                            |
| 46  | **Issued quotations are immutable in the database** (triggers). Revisions are new versions; issuing supersedes the previous version (marked `REVISED`; its link keeps working but is labelled Superseded). The enquiry moves to `QUOTATION_SENT` only from `NEW`/`CONTACTED`, recording the real previous status. |
| 47  | **The enquiry tracking link also opens the latest issued quotation**; quotations additionally have their own revocable link.                                                                                                                                                                                      |
| 48  | **Quotation documents carry only configured facts** (Business Settings + what the administrator typed). | 49  | **Callback stays a `GENERAL` enquiry** with a related `enquiry_callbacks` row; preferred date is validated in IST (not past, ≤30 days); time windows promise no clock times.                                                                                                                                      |
| 50  | **Search is word-boundary based with a narrow, code-owned synonym dictionary** (no Sheets column, no external service). Letters-only terms never match mid-word; short trade words match whole words only.                                                                                                        |
